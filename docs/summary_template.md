## 2. ปัญหาที่พบและวิธีแก้ (10 คะแนน) — อย่างน้อย 2 ข้อ
เขียนจากสิ่งที่คุณเจอจริง ในรูป  **อาการ → วิธีหาสาเหตุ → วิธีแก้**  เช่น (ตัวอย่างหัวข้อที่มักเจอ ใช้เมื่อเจอจริงเท่านั้น)
- ร้านตอบ 403 / robots.txt ห้ามเก็บ → ดู log ของ task + `scripts/probe.py robots` → เปลี่ยนแหล่ง
- ISBN ไม่ตรงกันข้ามร้าน → เทียบ ISBN ของหนังสือเล่มเดียวกัน พบว่า e-book กับฉบับเล่มคนละเลข → กรองเฉพาะฉบับเล่ม
- ราคา/ISBN ว่างหลัง parse → เปิดหน้าจริงดู HTML → ปรับ regex ใน `parsers.py`
